SIWZ-RAG v4

RAG do oceny wymagań SIWZ/RFP względem dokumentacji Cortex

Wklejasz wymaganie z polskiego przetargu (SIWZ/SWZ/OPZ) — aplikacja przeszukuje lokalny mirror dokumentacji Palo Alto Cortex i wydaje werdykt z uzasadnieniem, z linkami do źródeł w oficjalnym portalu. Wszystko działa lokalnie.

⭐ Repo na GitHub 📖 Instalacja 📦 Releases

Co potrafi

🔍

Weryfikacja wymagań

Pojedyncze wymaganie SIWZ → ocena ✅/⚠️/❌ z chain-of-thought.

✍️

Generowanie wymagań

Z tematu → N wymagań technologicznie neutralnych. Opcjonalna anonimizacja.

📄

Analiza całego SIWZ

PDF/DOCX → lista wymagań → ocena każdego → raport Markdown.

🔄

Auto-sync z portalem

Incremental update z oficjalnego API — tylko delty.

🛡️

100% lokalnie

Żaden tekst SIWZ nie opuszcza Twojego laptopa. Wszystko offline po sync.

Dwujęzycznie

UI i odpowiedzi w PL lub EN. Słownik terminów SIWZ ↔ Cortex.

Quickstart (5 minut)

# Wymagania: Python 3.11/3.12, Ollama, 16 GB RAM
git clone https://github.com/n0081183/siwz-rag-v4.git
cd siwz-rag-v4
bash scripts/setup.sh         # venv + paczki + modele Ollama
source .venv/bin/activate
siwz-rag doctor               # health-check
siwz-rag sync                 # pierwsza sync ~30-60 min
siwz-rag serve                # UI: http://localhost:8501
